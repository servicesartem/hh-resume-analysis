# Анализ резюме из HeadHunter

Итоговый проект модуля «Python для анализа данных». Задача — подготовить базу резюме hh.ru к модели, которая предсказывает желаемую зарплату соискателя.

## Что сделано

- Исследована структура данных: 44 744 резюме, 12 признаков.
- Преобразованы признаки: уровень образования, пол и возраст, опыт работы в месяцах, город и готовность к переезду и командировкам, one-hot кодирование занятости и графика, зарплата в рублях по курсу на дату обновления резюме.
- Проведен разведывательный анализ: распределения возраста, опыта и зарплаты, зависимость зарплаты от образования, города, готовности к переезду и командировкам, возраста и образования. Добавлены два графика: разрыв в зарплате мужчин и женщин по городам и зарплата по видам занятости и графикам работы.
- Очищены данные: удалены дубликаты, пропуски, выбросы по зарплате, опыту и возрасту (метод z-отклонений в логарифмическом масштабе). В итоговой таблице 44 482 резюме.

## Файлы

- `Итоговый проект hh.ipynb` — решение с кодом, графиками и выводами.
- `ExchangeRates.csv` — курсы валют к рублю с 29.12.2017 по 05.12.2019.
